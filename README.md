# Тир (pygame)

Игра «Тир» на pygame: окно 800×600, мишень появляется в случайной точке случайного цвета, попадания засчитываются по клику мыши. Спрайты и иконка окна — в папке `img/`.

Что внутри с точки зрения кода: игровой цикл, обработка событий мыши, работа со спрайтами и координатами.

## Запуск

```bash
pip install pygame
python main.py
```
